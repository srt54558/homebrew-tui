# Homebrew tap for tui

```sh
brew install srt54558/tui/tui
```

`tui` opens terminal apps by their domain. This tap holds only the formula; it downloads the signed release files from `https://tui-get.k-plus.one`. Builds installed through Homebrew are updated with `brew upgrade`, never by tui itself.

The formula is generated for each release by the tui release tooling. No release has been published yet.
